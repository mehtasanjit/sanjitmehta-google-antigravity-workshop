# Google HTML/CSS Style Guide Summary

## 1. General Rules
- Use UTF-8 encoding.
- Indent by 2 spaces.
- Semantic HTML tags (`<header>`, `<main>`, `<section>`, `<article>`, `<button>`, `<dialog>`).
- Valid accessibility attributes (ARIA roles, labels, focus handling).

## 2. CSS Styling & Layout
- Use modern Tailwind CSS utility classes and modern CSS variables for themes.
- Responsive layout with Flexbox and CSS Grid.
- Avoid inline styles where classes apply.
