# Product Guidelines: Banking Complaint Resolution Workbench

## Design Principles
1. **Simplicity First**: Minimal cognitive overhead. The primary workspace is an organized Kanban board with clear status columns, color-coded priority badges, SLA indicators, and intuitive modal views for details.
2. **Action-Oriented Role Experience**: Make what the active role needs to do obvious. If a supervisor logs in, high-priority cases pending review are highlighted. If a handler is logged in, their assigned active investigations are front and center.
3. **Clarity and Transparency**: Financial redress, customer impact summary, and investigation findings must be presented clearly with zero ambiguity.
4. **Audit Immutability**: All timeline changes are visible in a clean chronological audit log view with timestamp, actor name, action type, and comments.

## Visual & Interaction Guidelines
- **Color Palette**: Professional banking theme (Deep Navy `#1e293b`, Slate `#475569`, Emerald `#059669` for resolved/approved, Amber `#d97706` for review, Rose `#e11d48` for escalated/high priority).
- **Typography**: Clean sans-serif system fonts (Inter / Roboto / system-ui).
- **Responsiveness & Usability**: Full desktop and tablet layout support with keyboard navigation for modal dialogues.
- **Tone of Voice**: Professional, concise, compliance-oriented banking terminology.
