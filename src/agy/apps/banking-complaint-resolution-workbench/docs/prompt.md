# Initial Prompt

Build the Banking Complaint Resolution Workbench described in `../docs/requirements.md`.

Begin by reading the workspace `AGENTS.md` and the complete requirements. Use the installed specification-driven development workflow to clarify any material ambiguity, produce a product specification, identify the significant design decisions, and propose an implementation plan before writing application code. Ask for confirmation where required by the workspace guidance.

After the specification and significant design decisions are approved, implement only the agreed initial scope and verify the completed behavior against the requirements and acceptance criteria. Use only synthetic banking and customer data. Do not add external integrations, production authentication, or agentic features unless they are separately requested and approved. Clearly report anything incomplete or unverified.
