# Technology Stack: Kanban Board Application

## Core Runtimes & Frameworks
- **Framework:** React 18 (`react ^18.2.0`, `react-dom ^18.2.0`)
- **Build Tooling:** Vite (`vite ^5.1.6`, `@vitejs/plugin-react ^4.2.1`)
- **Module Format:** ES Modules (`"type": "module"`)

## UI & Styling
- **Styling:** Vanilla CSS (`src/index.css`) with CSS custom properties (variables)
- **Icons:** Lucide React (`lucide-react ^0.344.0`)

## State Management & Storage
- **State Logic:** React `useState` & Custom Hook (`useKanban`)
- **Persistence:** Browser `localStorage` API + JSON Import/Export

## Development & Environment
- **Node.js Environment:** Package scripts (`npm run dev`, `npm run build`, `npm run preview`)
- **Type Checking Support:** `@types/react`, `@types/react-dom`
